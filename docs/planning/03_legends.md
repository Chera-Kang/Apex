## 1. 📋 기획 (Planning : Why & UI Flow)

### 1) 왜 필요한가? (User Value)
- 에이펙스 레전드는 레전드의 스킬과 클래스 고유 특전(Class Perks), 그리고 시즌 20 이후 추가된 레벨별 특전 선택(Upgrade Perks)이 승패를 좌우합니다.
- 유저는 한 화면에서 5대 클래스별 레전드를 필터링하고, 원하는 레전드의 **스킬 쿨다운, 사용 횟수, 퍽 선택지**를 모달창으로 깔끔하게 확인하길 원합니다.

### 2) 화면 구성 및 인터랙션 흐름 (UI Flow)
1. **GNB 진입**: 상단 `[ 레전드 ]` 탭 클릭 또는 URL `#legends` 직접 접근.
2. **역할군 필터 탭 (Class Perks 안내)**:
   - `[전체]` `[어썰트]` `[스커미셔]` `[리콘]` `[서포트]` `[컨트롤러]` 5대 역할군 필터 버튼 제공.
   - 탭 선택 시 해당 역할군의 고유 인게임 혜택(예: *서포트 = 배너 제작 가능, 어썰트 = 레드 무기 빈 오픈*) 안내 바 표시.
3. **레전드 카드 그리드**:
   - 28종 레전드 썸네일, 한/영 명칭, 역할군 뱃지.
4. **상세 정보 모달창 (Modal View)**:
   - 카드를 클릭하면 팝업 모달이 부드럽게 열림:
     - **프로필 & 스토리**: 레전드 배경 스토리 및 타이틀
     - **스킬 3종**: 패시브, 전술 스킬(쿨다운/사용 횟수), 궁극기(충전 시간)
     - **업그레이드 특전(Perks)**: 레벨 2 (좌/우 선택지 2개), 레벨 3 (좌/우 선택지 2개)

## 2. ⚙️ 개발 (Dev : Data & Implementation)

### 1) 하이브리드 데이터 아키텍처
무기와 달리 레전드는 긴 줄글과 계층 구조(스킬/퍽 트리)를 가지므로, **시트 요약본 + JSON 상세본**의 하이브리드 구조를 사용합니다.

```
[ wiki.gg 크롤러 ]
        │
        ├──▶ 1. 구글 스프레드시트 ('Legends' 탭) : 쿨다운/역할군 정렬용 핵심 9개 칼럼 요약표
        │
        └──▶ 2. 로컬 JSON ('data/legends_data.json') : 모달 렌더링용 계층형 상세 데이터 (줄글, 퍽 트리)
```
