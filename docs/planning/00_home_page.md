## 1. 🎯 메뉴 개요 및 목적 (Overview & Goal)
- **목적**: 사이트 접속 시 유저가 마주하는 첫 화면으로, 에이펙스 레전드 인게임 로비 특유의 SF 테크니컬 분위기를 전달하고 주요 기능(무기 도감, 레전드, 계산기)으로 즉시 이동할 수 있는 **'작전 통제실(Command Center)'** 역할을 수행한다.
- **핵심 유저 가치**:
  - 접속 즉시 "현재 진행 중인 실시간 맵과 남은 시간"을 3초 만에 파악.
  - 원하는 분석 기능(도감, 계산기 등)으로 원클릭 진입.

## 3. 🚶 사용자 워크플로우 & 인터랙션 (1, 2, 3 Steps)

### Step 1: 상단 GNB 로비 메뉴 조작
1. 상단 중앙 정렬된 메뉴바에서 **`[ 홈 ]`**이 기본 활성화(Active) 상태로 노출된다.
2. 활성 탭 밑에는 **Apex Red 사선 컷팅 라인(`--accent-red`)**이 켜져 인게임 로비의 느낌을 준다.
3. 다른 메뉴(`[ 무기 도감 ]` 등)를 클릭하면 화면 전체 새로고침 없이 부드럽게 해당 메뉴 화면으로 전환된다.
4. 좌측 상단 `APEX INFO` 로고를 클릭해도 언제든 홈으로 복귀한다.

### Step 2: Hero 라이브 배너 확인
1. 상단 배너에서 현재 시즌 타이틀과 실시간 맵 로테이션 상태를 확인한다.
2. `[맵 로테이션 보기]` 버튼을 누르면 맵 메뉴로 바로 이동한다.

### Step 3: 핵심 포털 카드를 통한 기능 진입
1. 3개의 대형 사선 모서리 카드(무기 도감, 레전드, TTK 계산기)에 마우스를 올리면 은은한 레드/블루 네온 글로우 효과가 발생한다.
2. 카드를 클릭하면 해당 세부 기능 페이지로 즉시 점프한다.
