## 1. 📋 기획 (Planning : Why & UI Flow)

### 1) 왜 필요한가? (User Value)
- 플레이어들이 매일 게임 켜기 전 사이트에 접속하게 만드는 **'살아있는 정보 허브'** 역할을 수행합니다.
- 복잡하고 긴 공식 영문 패치노트를 일일이 찾지 않아도, "지금 무슨 맵인지", "이번 주에 어떤 총기가 버프/너프되었는지"를 3초 안에 직관적으로 파악할 수 있습니다.

### 2) 화면 구성 및 인터랙션 흐름 (UI Flow)
1. **메인 홈 연동 & 전용 탭**:
   - 메인 홈 대시보드의 우측 패널 및 상단 `[ 맵 / Info ]` 탭(URL `#maps`)에서 접근 가능.
2. **실시간 전장 로테이션 (Map Rotation)**:
   - **일반 배틀로얄 (Pubs)**: 현재 맵(올림푸스 등) 및 남은 시간 초 단위 카운트다운 타이머, 다음 예정 맵 안내.
   - **랭크 배틀로얄 (Ranked)**: 현재 랭크 맵 및 스플릿 기간 안내.
3. **최신 패치노트 & 뉴스 카드 (Patch Highlights)**:
   - 공식 공지사항 및 핫픽스 요약 목록 제공.
   - 각 항목별 **`BUFF(초록색)`**, **`NERF(빨간색)`**, **`ADJUST(주황색)`** 태그를 직관적으로 부여.

## 2. ⚙️ 개발 (Dev : Data & Implementation)

### 1) 데이터 수집 및 연동 전략
- **맵 로테이션**: ALS Open API (`https://apexlegendsapi.com/`) 엔드포인트 연동 및 클라이언트 1분 로컬 캐싱 적용.

## 3. ✅ 검증 및 완료 기준 (Verification & DoD)

### v1.0 완료 기준 (MVP 목표)
- [ ] 맵 로테이션 타이머가 브라우저에서 1초 단위로 부드럽게 감소하고 만료 시 다음 맵으로 전환될 것.
- [ ] 최신 패치노트 하이라이트가 버프/너프 태그와 함께 명확히 렌더링될 것.
- [ ] API 미응답 또는 네트워크 오류 시 로컬 캐시 데이터 기반 안전 폴백(Fallback)이 작동할 것.

### v1.2 확장 완료 기준 (차기 백로그)
- [ ] 무기별 패치 전/후 수치(데미지, RPM 등)를 교차검증 스크립트와 연계하여 자동 Diff 뱃지 노출.
